This talk will discuss challenges and strategies for porting existing HLSL codebases to the Slang shading language, with an emphasis on navigating the difference between HLSL templates and Slang generics.

Slang is a modern GPU language with broad cross-platform support and a familiar HLSL-inspired syntax. But Slang isn't the same as HLSL, and the differences can make it challenging to bring a large HLSL codebase to Slang.

We will discuss challenges for HLSL-to-Slang porting, and the best practices we have learned, with a focus on the challenges of porting code that uses HLSL templates to use Slang generics instead. Along the way, we'll discuss new standard modules that have been added to Slang to simplify some of these porting tasks, along with a set of agent skills that improve agent performance and code quality when assisting you in porting HLSL to Slang.
